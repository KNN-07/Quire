These are Latin subsets. Characters not in these files fall through to system-ui,
monospace, or Georgia/serif as declared in the tokens. Mono emphasis uses browser
weight synthesis; a separate Mono bold file is not shipped. Fonts use swap so
initial content is never blocked on a font response.
