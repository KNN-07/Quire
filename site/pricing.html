Pricing

Free to run yourself

Quire has one edition. You install it on your own infrastructure, and every capability is unlocked. Hosted plans exist only where an operator chooses to offer them.

Self-hosted

Unbilled

No license key. No seat limit. No feature gates.

  • Source, Split, Visual, and PDF views
  • Shared editing, comments, and review
  • Real project Git repositories
  • Optional AI and identity providers you configure
Install Quire Server

Hosted by an operator

An institution or provider that runs Quire can configure its own plans, billing periods, and prices.

  • Prices appear on that installation's own pricing page
  • Billing is per organization

Billing questions

Do my collaborators need a paid plan?

No. A self-hosted installation has no commercial feature gates. Sharing and account policy are yours to configure.

Does AI cost extra?

Quire does not charge for it. You pay whichever model provider you configure, and you can set a daily usage budget.

Is there a hosted version I can sign up for?

This project does not run a public hosted service. If your institution runs Quire, its pricing and terms come from that operator.

Can I get support?

There is no bundled support plan. The repository documents installation, operation, and recovery.
