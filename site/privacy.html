Privacy

What Quire stores, and where

This describes the software's default data handling. Whoever operates your installation decides its storage, retention, and external providers, and is the one to ask for a privacy policy.

This website

This site is a set of static pages served by GitHub Pages. It sets no cookies, loads no third-party scripts, and includes no analytics. GitHub may log requests as described in its own privacy statement.

Sign-in and browser storage

Signing in to a Quire installation sets an HttpOnly session cookie with a seven-day expiry. Server-side expiry and revocation can end access earlier.

The browser can remember editor layout, Python configuration, Dropbox selections, and operation IDs. Track Changes recovery keeps private draft text in session storage. Signing out does not clear all browser storage, and clearing site data can discard unsubmitted drafts without deleting anything on the server.

Analytics

Quire includes no advertising or analytics integration. An operator may separately configure proxy logs or extensions; ask them what those collect.

External providers

Configured identity, AI, mail, Git, reference, Dropbox, billing, and publisher services have their own terms. Connecting a service or sending content to it can disclose data to that provider.

AI requests require consent to the current configured terms. Operator logging of AI requests is off by default.

Export and deletion

An account export contains account metadata. Project source and history are exported separately. Passwords, session secrets, and provider credentials are never included. Ask your operator about retention periods and how to request access or deletion.
